# DSH-Dock

> dsh 分布式开发工具链的 Windows 桌面管理端

DSH-Dock 是 dsh（DeepSeek Harness）在 Windows 上的桌面入口与管理界面，基于 Python + Tray 守护进程实现，提供多实例管理、插件市场、手机连接等能力，并产出**免安装的绿色版 DSH-Dock.exe** 用于分发。

## 功能一览

| 功能 | 说明 |
|---|---|
| 多实例管理 | 端口 / 工作区控制，运行监控，崩溃 10 秒内自动重启守护 |
| 三种打开方式 | 嵌入浏览器 / 系统终端 TUI / Web 界面 |
| 凭证中心 | API Key 管理、余额查询、会话统计 |
| 插件市场 | 浏览 / 安装 / 启动插件 |
| 手机连接 | 一键开启局域网访问，手机浏览器直接用 |
| 定时任务 | 计划任务配置 |
| 启动页配置 | 管理界面(3999) 或 工作页(3080) 二选一 |
| 自动更新 | stable / beta / alpha 通道选择 |
| 开机自启 | 托盘守护，default 实例随系统启动 |

## 环境要求

- Windows 10 / 11（64 位）
- 预装 [Node.js](https://nodejs.org)（含 npm）
- 首次运行如遇 SmartScreen 提示，选择「仍要运行」即可

## 使用说明

1. 双击运行 DSH-Dock.exe，托盘图标出现即启动成功
2. 系统托盘：单击打开管理界面(3999)，双击打开工作页(3080)
3. 首次使用可在管理界面检查并安装推荐插件包（新人推荐 6 件套）

### 手机访问

管理界面点击「手机连接」→ 一键将 3080 端口开放到局域网 → 手机浏览器访问界面显示的链接即可，关闭后自动恢复本机独占。

## 配置

配置文件固定位于用户主目录 C:\Users\<用户名>\dsh.ini，首次运行自动生成；支持从旧位置（%APPDATA%\DSH-Dock、exe 目录）自动迁移。
